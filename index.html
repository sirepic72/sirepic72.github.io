StreamTracker

StreamTracker is a personal tool run by Iroquois Pliskin that adds upcoming livestreams to their own Google Calendar.

Privacy Policy

StreamTracker is a personal tool run by Iroquois Pliskin for their own use. It is not offered to the public.

What it accesses: With permission from the account owner, StreamTracker uses Google Calendar to add, update and remove events for upcoming livestreams. It uses Google Drive only to create and update files it made itself (a daily review file in a StreamTracker folder).

What it stores: Its sign-in token and logs are kept on the owner's own PC. It doesn't collect, sell or share any data with anyone, and it doesn't access any other calendar events or Drive files.

Removing access: You can revoke StreamTracker's access at any time at myaccount.google.com/permissions.

Terms of Service

Use: StreamTracker is meant to be used only with the owner's own Google account. It reads public livestream schedules and adds, updates or removes matching events on the owner's Google Calendar, and saves a daily review file to the owner's Google Drive.

No warranty: StreamTracker is provided as-is, with no guarantee that it works correctly or all the time. Stream times come from public sources and may be wrong, late or missing.

Liability: The owner isn't responsible for missed streams, wrong calendar events or any other problem caused by using StreamTracker.
